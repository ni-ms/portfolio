# Ticket reports

Create one Txx.md report per active ticket. The assigned worker owns that report; the coordinator owns state.json and PROGRESS.md.

Keep each report concise. Include owner, worktree/branch, base/result SHA or patch, changed paths, implementation summary, actual checks and evidence, known gaps, dirty files, remaining work, and the exact next action. Update it before every session/context transition, including incomplete work.

Never use this directory for raw logs, full transcripts, base64 images, or dependency dumps. Raw execution logs belong in ignored .agent-runs/.
