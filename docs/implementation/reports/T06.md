### P2 R2: Dynamic Badge Measurement & Collision-Free Separation
1. **Measured Rendered Dimensions**:
   - Eliminated hardcoded `146x46` assumptions in `SceneMarkers.tsx`.
   - Attached React DOM refs (`badgeRefs`) to each `<a>` waypoint badge (`01 / WORK`, `02 / EXPLORATIONS`, `03 / RÉSUMÉ`).
   - Attached a `ResizeObserver` and `document.fonts.ready` listener to continuously measure actual rendered bounding box dimensions (`getBoundingClientRect()`), dynamically accommodating arbitrary font sizes, user zoom, and text preferences (including Chromium `minimumFontSize=18` and `minimumFontSize=22`).

2. **Containment Without Clipping**:
   - Each badge's screen-space position is constrained within canvas safe insets:
     - `x` clamped to `[insetLeft, canvasWidth - insetRight - measuredWidth]`.
     - `y` clamped to `[insetTop, canvasHeight - insetBottom - measuredHeight - leaderHeight]`.
   - Because `measuredWidth` (up to ~238px at `minimumFontSize=22`) is subtracted from `canvasWidth`, the right edge of every badge strictly remains inside the canvas boundaries (`right <= canvasRight`). Zero overflow clipping occurs in `.scene-markers-portal`.

3. **Pairwise Collision Avoidance**:
   - Implemented a coordinated layout solver in `resolveCollisionFreeLayout`:
     - Detects pairwise collisions among all 3 badges (`overlaps(a, b)`).
     - When unconstrained (e.g. Desktop 1585, 1440, Tablet 768), badges remain at their natural 3D projected overview positions.
     - When constrained/colliding on narrow mobile screens (390px, 360px), badges are separated vertically with guaranteed 8px margins:
       - `01 / WORK` remains at its natural elevation above the rooftop terrace as the primary next landing.
       - `03 / RÉSUMÉ` is positioned below Work with clear separation.
       - `02 / EXPLORATIONS` is positioned below Résumé with clear separation.
     - Leader SVG elements have `pointerEvents: 'none'`, preventing leader lines from intercepting mouse clicks.
     - Pairwise overlap is strictly 0px across all pairs.
     - Independent hit targets: `document.elementFromPoint` at center and text center of each badge hits only that badge.
     - Direct pointer clicks on Work text navigate to `/projects` (`workTextOverlapHeight === 0`).
     - Real pointer clicks on Résumé and Explorations navigate to `/resume` and `/about`.
     - Full keyboard Tab sequence through all 3 markers produces zero horizontal document pan (`scrollX === 0`, `docWidth <= viewport`).
