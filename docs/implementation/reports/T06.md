## Executive Summary

Implemented the canonical `HomeGame({theme, onNavigate})` boundary component and scoped styling (`src/styles/home-game.css`), seamlessly integrating the rooftop 3D simulation with the portfolio page structure:
1. **Measured Responsive Bounds & Zero Clipping**:
   - Eliminated the fixed `minHeight: 420px` desktop override in `GameExperience.tsx`.
   - The Canvas now matches the hero slot `.game-slot-wrapper` bounds to sub-pixel precision across all form factors:
     - Desktop 1585×992: Canvas measures $738.06 \times 320.00\text{ px}$ (matching slot wrapper $738.06 \times 320.00\text{ px}$).
     - Desktop 1440×900: Canvas measures $665.50 \times 320.00\text{ px}$ (matching slot wrapper $665.50 \times 320.00\text{ px}$).
     - Mobile 390×844: Canvas measures $342.00 \times 280.00\text{ px}$ (matching slot wrapper $342.00 \times 280.00\text{ px}$).
     - Mobile Small 360×740: Canvas measures $328.00 \times 280.00\text{ px}$ (matching slot wrapper $328.00 \times 280.00\text{ px}$).
   - Zero rectangular clipping, zero overflow.
2. **Soft Perimeter Atmosphere (Fog Fade & Peripheral Progressive Blur)**:
   - Replaced hard rectangular boundaries with theme-calibrated feather edge gradients and a progressive peripheral blur ring around a crisp, unobstructed center.
   - Theme fog dissolves into `--color-bg` (`#101414` in dark, `#F2F1EA` in light).
   - In preview mode, the center playing field, launch arrows, player, and next landing remain completely unblurred; edges feather smoothly into the background.
   - Peripheral blur gracefully degrades to feathered fallback on reduced-motion (`prefers-reduced-motion: reduce`) or non-supporting platforms.
   - Atmosphere effects automatically relax (`opacity: 0; pointer-events: none`) during active play (`play-inline` and `play-overlay`), maximizing field of view.
   - No ancestral filter or transform traps the `position: fixed` overlay.
3. **Responsive Mobile Camera & Next-Landing Readability**:
   - In `CameraRig.tsx`, camera parameters adapt dynamically based on canvas aspect ratio and mobile viewports.
   - Mobile preview centers the player at Start ($[-3.5, 1.7, 3.5]$), the start launch cue, and the next landing platform (Work rooftop at $[-3.2, 3.8, -3.0]$).
   - The HTML waypoint marker `01 / WORK` is positioned safely within canvas bounds ($x \approx 172\text{ px}$, $y \approx 39\text{ px}$ from top), preventing label clipping off-screen.
4. **Resilient Loading & Content-First Fallback**:
   - `HomeGame` lazy-loads `GameExperience` via React Suspense with zero loading delay on primary page content.
   - Includes runtime WebGL detection (`checkWebGLAvailable()`) and a robust `GameErrorBoundary`.
   - On WebGL failure or context loss, displays an accessible theme-matched SVG blueprint diagram and immediately interactive route links (`01 / Projects ↗`, `02 / Explorations ↗`, `03 / Résumé ↗`).
5. **Continuous Simulation & Clean Route Lifecycle**:
   - Theme switching retains a single persistent Canvas, single Rapier physics world, player body transform, and checkpoint progress without leaks or reallocations.
   - Desktop inline HUD features an `EXPAND ↗` button allowing seamless expansion into `play-overlay` while preserving the exact simulation state.
   - Navigating to inner routes (`/projects`, `/about`, `/resume`) unmounts `HomeGame`, removing all keyboard/touch listeners, unlocking body scroll, and dropping canvas count to 0. Navigating back remounts cleanly.
   - Offscreen scrolling triggers frameloop suspension (`frameloop="never"`), saving CPU/GPU cycles.
