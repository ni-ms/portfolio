## Executive Summary

Ticket T07 implements the portfolio motion system adhering strictly to single-property ownership, immediate content availability, and live reduced-motion support across both themes and all responsive viewports.

### Architectural Principles & Property Ownership
1. **Single Property Ownership**:
   - Physics exclusively drives player movement and velocities.
   - Frame loop in `CameraRig.tsx` alone writes camera transforms via lerp interpolation.
   - GSAP coordinates transition target offsets (`liveCameraTransition`) and DOM property state.
2. **Immediate Content Availability**:
   - Zero content is trapped at `opacity: 0` or behind endless staggers.
   - Navigation, CTAs (`/resume`, `/about#contact`), and keyboard Tab focus remain functional from the initial frame.
   - Timelines duration capped at <=0.5s with subtle translate offsets (8–14px).
3. **Accurate Benchmark Bar Reveals**:
   - In `BenchmarkComparison.tsx`, factual numbers (`684 µs`, `539 µs`, `▼ 21%`, `~91%`, `145 µs`) and primary-workload qualifier remain static and legible.
   - GSAP reveals baseline (100%) and optimized (78.8%) bars using GPU-accelerated `scaleX` from `left center` (0.6s–0.7s `power2.out`).
4. **Live & Initial Reduced Motion**:
   - Under `(prefers-reduced-motion: reduce)`, all reveals clear immediately (`clearProps: 'all'`), camera drone hover drift is zeroed, and benchmark bars render at full target width without delay.
   - Live media query listeners immediately cancel active tweens and revert elements if reduced motion is toggled in real time.
5. **Lifecycle & Route Cleanup**:
   - All page entrance animations are wrapped in scoped GSAP contexts (`usePageMotion`) keyed to the normalized route path.
   - Switching routes reverts all timelines and kills active ScrollTriggers, preventing trigger leaks and stale styles.
   - Repeated route cycling and back/forward navigation preserve zero horizontal pan (`scrollWidth <= innerWidth`).
6. **Restrained Theme Transition**:
   - Theme toggle adds `.theme-transitioning` to `<html>` for 220ms, smoothly easing background and border colors on DOM containers while strictly exempting the 3D canvas and game wrappers.
   - Instantly bypassed when reduced motion is preferred.
7. **Checkpoint & Interaction Polish**:
   - Reaching an unlocked checkpoint displays a subtle, non-blocking lime pulse acknowledgement on the banner (`.checkpoint-acknowledge-active`).
   - Project cards feature subtle 2px lift, accent border glow, and thumbnail scale without layout shift. Native modifier/new-tab clicks are fully preserved.
