### 2.2 Theme Persistence & Contrast Verification
- **Dark Default First Paint**: Pre-paint inline script in `index.html` evaluates `localStorage.getItem('nikhil-portfolio-theme')`, defaulting to `dark` before React render to avoid light flash.
- **Persistent Theme Choice**: User choice persists across routes, reloads, and browser sessions.
- **Storage Failure Resilience**: If `localStorage` access is restricted (e.g. `SecurityError` or private browsing), the application falls back safely to dark mode without throwing unhandled exceptions.
- **Restrained 220ms Transition**: Theme changes apply a scoped `.theme-transitioning` class to DOM elements for 220ms while strictly exempting the 3D canvas and game wrappers. Bypassed immediately under reduced motion.
- **Color Contrast Compliant**: All typography meets WCAG AA / AAA standards (touch control panels exceed 9.45:1 contrast against dark/light backdrops).

### 2.3 Interactive 3D Rooftop Simulation & Mechanics
- **Single Property Ownership**: Physics simulation (`@react-three/rapier`) exclusively drives player position and velocity; Three.js frame loop in `CameraRig.tsx` alone writes camera transforms via smooth lerp interpolation; GSAP coordinates numerical transition target offsets (`liveCameraTransition`) and DOM states.
- **Framing & Responsiveness**: Sits cleanly in desktop side-by-side hero (`738px × 320px`) and mobile hero (`342px × 280px`) without horizontal scrollbar or document pan (`scrollWidth <= innerWidth`).
- **Dynamic Portal Scene Markers**: HTML badges for `01/WORK`, `02/EXPLORATIONS`, and `03/RÉSUMÉ` feature dynamic DOM measurement (`ResizeObserver`), horizontal canvas-edge clamping, and pairwise collision avoidance (`resolveCollisionFreeLayout`) to prevent label overlap under all viewports and enlarged font settings.
- **Multi-Touch & Mobile Expanded Play**: On touch devices, tapping "Play" / "Expand" engages an accessible touch overlay with D-pad cluster, Jump impulse, and Reset buttons. Body scroll locks cleanly and restores on exit.
- **Resilient Fallback**: Context loss (`webglcontextlost`) and lazy load rejection immediately present a readable blueprint fallback and working navigation links without locking input or scroll.

### 2.4 Purposeful Motion & Reduced Motion Coordination (T07)
- **Immediate Content Availability**: Zero elements trapped at `opacity: 0` or behind blocking timelines. CTAs and navigation are interactive from the initial frame.
- **Accurate Benchmark Bar Reveals**: Baseline (100%) and optimized (78.8%) bars scale smoothly using GPU-accelerated `scaleX` while all factual text and qualifier disclaimers remain static and legible.
- **Complete Reduced Motion Policy**: Under `(prefers-reduced-motion: reduce)`, animations resolve immediately, camera drift is zeroed, and active timelines revert cleanly on live media query toggle.
- **Lifecycle & Trigger Leaks**: All route animations run in scoped GSAP contexts that auto-revert on unmount, ensuring zero leaking ScrollTriggers across repeated route cycles.

## 5. Known Hardware Limitations & Performance Disclosures

1. **Hardware GPU vs. Emulated SwiftShader**:
   - Automated browser verification ran in headless Chromium with SwiftShader CPU rasterization.
   - Under SwiftShader, frame render times averaged ~57ms–60ms (~16–18 FPS). On native hardware GPUs (Apple Silicon / discrete GPUs), Three.js draw call counts (366 draws, ~7,026 triangles) and memory footprint are bounded to achieve smooth 60 FPS performance, but physical device hardware GPU testing is not fabricated.
2. **Missing Real Headshot Photo**:
   - As established in task briefing, Nikhil Sharma's actual physical headshot photograph was not provided; the application renders an intentional, accessible `<PhotoPlaceholder>` component with high-contrast geometric initials (`NS`) and accent indicator.
3. **Download Assets**:
   - Download links for `/downloads/nikhil-sharma-resume.pdf` and `.docx` point to static public assets bundled in the distribution.
